# Демонстрация этапа 1

Запустите `./run.sh`. В заголовке окна должно быть имя `VFS-17`.
Вводите команды по очереди; каждая команда запускается клавишей Enter
или кнопкой «Выполнить».

| № | Ввод в окне | Ожидаемый результат |
| --- | --- | --- |
| 1 | `ls` | Заглушка `ls`, аргументы `[]` |
| 2 | `ls -al "my folder"` | Аргументы `["-al","my folder"]` |
| 3 | `cd` | Заглушка `cd`, аргументы `[]` |
| 4 | `cd "$HOME"` | Один аргумент: домашний каталог из окружения ОС |
| 5 | `ls "${HOME}/Documents"` | Один аргумент: путь с раскрытой переменной |
| 6 | `cd '$HOME'` | Буквальный аргумент `["$HOME"]` |
| 7 | `ls \$HOME` | Буквальный аргумент `["$HOME"]` |
| 8 | `cd my\ folder` | Один аргумент `["my folder"]` |
| 9 | `unknown` | Ошибка неизвестной команды |
| 10 | `cd /one /two` | Ошибка аргументов с подсказкой синтаксиса `cd` |
| 11 | `ls -z` | Ошибка неизвестного флага |
| 12 | `cd ""` | Ошибка пустого пути |
| 13 | `cd "broken` | Ошибка незакрытой кавычки |
| 14 | `ls ${HOME` | Ошибка незакрытой переменной |
| 15 | `exit now` | Ошибка аргументов; окно остаётся открытым |
| 16 | `ls` | Диалог продолжает работать после ошибок |
| 17 | Пустой ввод | Нет команды, ошибки или нового вывода |
| 18 | `exit` | Окно закрывается, приложение завершается |

Пункты 1–8 показывают успешный ввод и разбор; пункты 9–15 — обработку
ошибок. Пункты 16–18 проверяют продолжение диалога и завершение.
На этапе 1 существование путей не проверяется: `ls` и `cd` остаются заглушками.

Автоматическая проверка: `./run.sh --test`.
GUI-тест использует события клавиатуры и мыши; защита этапа проводится
в видимом графическом окне с помощью этой последовательности.

## Выполненная проверка

5 октября 2026 года проект собран на macOS с Qt 6.10.0 и Apple Clang.
CTest: 3 из 3 наборов прошли без ошибок. Проверены парсер, диспетчер команд
и взаимодействие с GUI.

В видимом окне выполнены пункты 1–18: заглушки, раскрытие переменных,
буквальные значения в одинарных кавычках, экранирование, ошибки и продолжение
диалога. `exit now` оставил окно открытым; `exit` завершил приложение.
