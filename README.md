# Практическая работа № 1

Конфигурационное управление. Вариант 17. C++17, Qt 6, CMake.
Эмулятор UNIX-подобной оболочки с графическим интерфейсом.
Сейчас выполнен этап 1.

## Этап 1: REPL

- Создано окно с именем VFS-17 в заголовке.
- Добавлены ввод команд и вывод результата.
- Реализован парсер с раскрытием переменных ОС: `$HOME`, `${HOME}`.
- Добавлена обработка кавычек и экранирования.
- Сделаны заглушки `ls` и `cd`: выводят имя команды и аргументы.
- Добавлены ошибки для неизвестных команд и неверных аргументов.
- Команда `exit` закрывает приложение.
- Добавлены тесты парсера, команд и интерфейса.

## Запуск и тесты

Нужны CMake 3.21+ и Qt 6.5+ с модулями Core, Widgets и Test.

```sh
./run.sh          # сборка и запуск
./run.sh --test   # сборка и тесты
```

Если Qt не найден, укажите путь через `QT_ROOT`.
В VS Code: Terminal → Run Task → Qt: run.

Примеры команд в окне:

```text
ls -al "my folder"
cd "$HOME"
cd /one /two
exit
```
