# Практическая работа № 1

Конфигурационное управление. Вариант 17. C++17, Qt 6, CMake.
Эмулятор UNIX-подобной оболочки с графическим интерфейсом.
Выполнены этапы 1 и 2.

## Этап 1: REPL

- Создано окно с именем VFS-17 в заголовке.
- Добавлены ввод команд и вывод результата.
- Реализован парсер с раскрытием переменных ОС: `$HOME`, `${HOME}`.
- Добавлена обработка кавычек и экранирования.
- Сделаны заглушки `ls` и `cd`: выводят имя команды и аргументы.
- Добавлены ошибки для неизвестных команд и неверных аргументов.
- Команда `exit` закрывает приложение.
- Добавлены тесты парсера, команд и интерфейса.

## Этап 2: конфигурация

- Добавлены параметры `--vfs` и `--script`.
- При запуске выводятся заданные параметры.
- Стартовый скрипт выполняется построчно, ввод и вывод видны в окне.
- Первая ошибка останавливает скрипт, после этого доступен ручной ввод.
- Добавлены примеры и проверочные скрипты в `examples` и `scripts`.
- Путь VFS пока только сохраняется, загрузка будет на этапе 3.

## Запуск и тесты

Нужны CMake 3.21+ и Qt 6.5+ с модулями Core, Widgets и Test.

```sh
./run.sh          # сборка и запуск
./run.sh --test   # сборка и тесты
./run.sh --vfs demo.csv --script examples/startup.txt
```

Если Qt не найден, укажите путь через `QT_ROOT`.
В VS Code: Terminal → Run Task → Qt: run.

Без параметров используются `VFS-17.csv` и ручной ввод.
Стартовый скрипт — текстовый файл UTF-8, пустые строки пропускаются.
`scripts/test_parameters.sh` проверяет параметры запуска;
`scripts/demo_startup.sh` показывает выполнение скриптов и ошибки.

Примеры команд в окне:

```text
ls -al "my folder"
cd "$HOME"
cd /one /two
exit
```
