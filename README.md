# Практическая работа № 1

Конфигурационное управление. Вариант 17. C++17, Qt 6, CMake.
Эмулятор UNIX-подобной оболочки с графическим интерфейсом.
Выполнены этапы 1–5.

## Этап 1: REPL

- Создано окно с именем VFS-17 в заголовке.
- Добавлены ввод команд и вывод результата.
- Реализован парсер с раскрытием переменных ОС: `$HOME`, `${HOME}`.
- Добавлена обработка кавычек и экранирования.
- Сделаны заглушки `ls` и `cd`: выводят имя команды и аргументы.
- Добавлены ошибки для неизвестных команд и неверных аргументов.
- Команда `exit` закрывает приложение.
- Добавлены тесты парсера, команд и интерфейса.

## Этап 2: конфигурация

- Добавлены параметры `--vfs` и `--script`.
- При запуске выводятся заданные параметры.
- Стартовый скрипт выполняется построчно, ввод и вывод видны в окне.
- Первая ошибка останавливает скрипт, после этого доступен ручной ввод.
- Добавлены примеры и проверочные скрипты в `examples` и `scripts`.

## Этап 3: VFS

- Добавлена загрузка файловой системы из CSV.
- Вложенные каталоги задаются абсолютными путями, данные файлов — в base64.
- Файлы и каталоги хранятся в памяти, на диск не распаковываются.
- Добавлены ошибки загрузки и проверки формата.
- `vfs-init` оставляет пустой корень `/` и очищает выбранный CSV-файл.
- Добавлены примеры VFS: минимальная, с файлами и с тремя уровнями каталогов.

## Этап 4: основные команды

- `ls` показывает содержимое VFS, поддерживает `-a`, `-l` и несколько путей.
- `cd` меняет текущий каталог; поддерживаются `.`, `..` и `cd -`.
- `uniq [-cdui] файл` обрабатывает соседние повторы строк.
- `tail [-n N] файл ...` выводит последние N строк (по умолчанию 10).
- `history [N]` выводит историю; ошибки и команды скрипта тоже сохраняются.
- В приглашении отображается текущий каталог.
- Добавлены сценарии команд и ошибок в `examples/stage4*`.

`cd` без аргументов возвращает в корень VFS. `ls -l` показывает тип, права,
размер в байтах и имя. `uniq`: `-c` — счётчик, `-d` — повторы,
`-u` — одиночные строки, `-i` — без учёта регистра.
`uniq` и `tail` читают текст UTF-8 из VFS; `--` завершает обработку флагов.

## Этап 5: дополнительные команды

- `chmod [-Rv] режим путь ...` меняет права файлов и каталогов в памяти.
- Поддерживаются восьмеричные права `0`–`7777` и символьные режимы:
  `u+x`, `go-r`, `a=rw`, `u=rwx,g=rx,o=`, копирование `g=u`, условное `X`, `s`, `t`.
- `chmod -R` обрабатывает вложенные элементы; `-v` показывает изменения.
- `rm [-rRfdv] путь ...` удаляет записи VFS: `-r`/`-R` — рекурсивно,
  `-d` — пустые каталоги, `-f` — без ошибки для отсутствующих путей, `-v` — вывод результата.
- Корень, текущий каталог и его родители защищены от удаления.
- Добавлены сценарий `examples/stage5.txt` и примеры ошибок в `examples/stage5-errors`.
- После перезапуска загружается исходный CSV; команды его не меняют.

Права — атрибуты VFS; пользователи и umask не моделируются.
В символьном режиме без `u`, `g`, `o` выбраны все классы. Флаги `chmod` идут перед режимом.
Для имени с дефисом используйте `--`: `chmod 600 -- -file`, `rm -- -file`.

Формат CSV (UTF-8, одна запись на строку):

```csv
path,type,data
/,dir,
/docs,dir,
/docs/hello.txt,file,SGVsbG8K
```

У каталогов данные пустые. Родительский каталог должен быть указан в CSV;
корень добавляется автоматически. Пустой CSV означает пустой корень.

## Запуск и тесты

Нужны CMake 3.21+ и Qt 6.5+ с модулями Core, Widgets и Test.

```sh
./run.sh          # сборка и запуск
./run.sh --test   # сборка и тесты
./run.sh --vfs vfs/commands.csv --script examples/stage4.txt
./run.sh --vfs vfs/commands.csv --script examples/stage5.txt
```

Если Qt не найден, укажите путь через `QT_ROOT`.
В VS Code: Terminal → Run Task → Qt: run.

Без параметров используются `vfs/VFS-17.csv` и ручной ввод.
Стартовый скрипт — текстовый файл UTF-8, пустые строки пропускаются.
`scripts/test_parameters.sh` проверяет параметры запуска;
`scripts/demo_startup.sh` показывает выполнение скриптов и ошибки.
`scripts/test_vfs.sh` проверяет загрузку вариантов VFS;
`scripts/demo_vfs_init.sh` проверяет сброс на временных копиях CSV.
`scripts/test_stage4.sh` проверяет команды;
`scripts/demo_stage4_errors.sh` показывает ошибки каждой команды.
`scripts/test_stage5.sh` проверяет изменения в памяти и повторный запуск;
`scripts/demo_stage5_errors.sh` показывает ошибки `chmod` и `rm`.

Примеры команд в окне:

```text
ls -al /docs
cd /docs
uniq -c lines.txt
tail -n 2 long.txt
history
exit
```

Сценарий демонстрации: [docs/stage1-demo.md](docs/stage1-demo.md).
